# CareLens

CareLens is an AI-powered reflection and burnout-awareness application built using the Gemini 3 API in Google AI Studio.

It provides users with a quiet, non-judgmental space to reflect on their daily experiences. Instead of giving advice or diagnoses, CareLens listens, identifies emotional patterns and cognitive load, and offers gentle, supportive micro-actions to encourage self-awareness and resilience.

## Key Features
- Daily text or voice reflections
- Burnout risk awareness (Low, Moderate, High)
- Personalized micro-support responses
- Reflection history to track emotional patterns over time
- Non-clinical, non-medical design with safety boundaries

## Gemini 3 Integration
CareLens uses Gemini 3’s advanced reasoning capabilities to:
- Interpret emotional tone and mental load in user reflections
- Detect early burnout indicators without clinical labeling
- Generate compassionate, structured responses
- Maintain consistency and safety across interactions

## Deployment
The application is built in Google AI Studio and deployed as a public Google Cloud Run service.
